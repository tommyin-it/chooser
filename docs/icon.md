# Ikona Chooser

Źródło: `Resources/Chooser.png`. Wygenerowano wbudowanym narzędziem ImageGen, z przezroczystym tłem. Plik `Resources/Chooser.icns` zawiera rozmiary dla macOS; można odtworzyć go poleceniem `./scripts/icon.sh` (narzędzia systemowe `sips` i `iconutil`).

## Prompt

Use case: logo-brand. Create a finished macOS app icon for Chooser, a tiny local utility that chooses between two browsers. Square 1024x1024 composition. A single elegant rounded-square tile, graphite charcoal with subtle satin depth, on genuinely transparent surroundings, generous standard macOS icon margin. Central crisp silver-white branching arrows: one stem rising from bottom center, splitting smoothly into two paths ending in clear arrowheads pointing upper-left and upper-right. Inspired by the simple macOS arrow.triangle.branch symbol. Bold clean geometry, balanced negative space, unmistakable at 32 pixels. Restrained monochrome white/gray palette, soft highlights, subtle dimensional polish, no busy reflections. No text, no letters, no browser logos, no mockup, no extra objects. The image itself is the app icon asset, not a presentation.
